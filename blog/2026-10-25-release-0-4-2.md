## Overview

:::caution **Security Release: eMudhra CA Trust Compromise Mitigation**

 This release addresses the security risks associated with the eMudhra certificate authority trust compromise.

 The container images (operator, prometheus-exporter, healthcheck) have been rebuilt using new base images to mitigate exposure to the affected CA trust chains.

For additional context, affected versions, and remediation guidance, please consult the following site: [eMudhra — We Have a Problem](https://emudhra.we-have-a-problem.com/).
:::

:::danger

- Users are strongly encouraged to **upgrade immediately** to this release
- **Do not use versions prior to** `0.4.2`

:::
